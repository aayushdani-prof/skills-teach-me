# Artifact (Reteach) rule

## Purpose
Prove the learner can REBUILD the concept. Exam proves memory under pressure;
artifact proves production. Both are required for hire-readiness.

## Rules (non-negotiable)
1. The LEARNER authors everything: explanation, worked steps, failure modes, diagram.
2. You grill like a demanding interviewer. Ask targeted questions; never answer for them.
3. Every gap found = logged as a gap; it re-enters the review queue until resolved.
4. You may ONLY restructure learner content, render their diagram from their own words,
   format tables/typos. Anything you added that isn't theirs = `[M]` tag, flag for verification.
5. Written to `<repo>/artifacts/<module>/` (runtime-owned path).

## Gate
- Core module: artifact_status `done` + exam `passed` -> module `off_docket`.
- Non-core: artifact strongly pushed; learner can override per lesson.
